# Video Thumbnail Generation in Nova Video Player

This document describes the end-to-end architecture and workflow for generating video thumbnails, the components and classes involved, configuration settings, and `adb` shell commands for debugging and verification.

---

## 1. Overview

Nova displays video posters and thumbnails across the UI:
- **Scraped videos** display official artwork (posters/backdrops) downloaded from TMDb.
- **Unscraped videos** (e.g. home videos, recordings, or files not matched on TMDb) display video thumbnails generated by extracting a representative frame directly from the media file.
- Thumbnail extraction works for both **local storage** and **remote shares** (SMB, SFTP, FTP, WebDAV, UPnP).

---

## 2. Architecture & Pipeline

```
[UI Layer]
  PosterImageCardPresenter / NonScrapedVideosFragment
          │ (posterUri == null)
          ▼
  ThumbnailRequestHandler (Picasso plugin)
          │ requests "thumbnail://<videoId>"
          ▼
[Media Provider / Database Layer]
  VideoStore.Video.Thumbnails.getThumbnail()
          │ 1. Check if thumbnail already in videothumbnail table
          │ 2. If not, issue blocking query:
          │    content://com.archos.media.videocommunity/external/video/thumbnails?blocking=1&orig_id=<videoId>
          ▼
  VideoProvider.queryThumbnail()
          │ constructs clean origUri: .../external/video/media/<videoId>
          ▼
  VideoProvider.waitForThumbnailReady()
          │ checks magic, nbTry < THUMB_TRY_MAX, and pref_create_remote_thumbs
          │ enqueues MediaThumbRequest (PRIORITY_HIGH) to mMediaThumbQueue
          │ blocks waiting for State.DONE
          ▼
  mThumbHandler (HandlerThread: "thumbs thread")
          │ processes IMAGE_THUMB -> MediaThumbRequest.execute()
          ▼
  VideoProvider.createVideoThumbnail()
          │ checks !LoaderUtils.getScrapeInProgress()
          ▼
[Metadata Retriever / Proxy Layer]
  AvosMediaMetadataRetriever.setDataSource(filePath)
          │ For remote URLs (smb://, upnp://, etc.):
          │ Proxy.setDataSource() -> starts StreamOverHttp (127.0.0.1:port)
          ▼
  AvosMediaMetadataRetriever.getFrameAtTime(-1)
          │ JNI call
          ▼
[Native libavos Layer]
  Java_com_archos_medialib_AvosMediaMetadataRetriever_nativeGetFrameAtTime()
          │
          ▼
  avos_mr_getframe()  (Source/avos_mr.c)
          │ creates thumb_stream (STREAM_THUMB pipeline)
          │ seeks to target frame: MIN(THUMB_TIME, duration / 2)
          ▼
  thumb_stream_get_frame()  (Source/thumb_stream.c)
          │ decodes video frame via FFmpeg / hardware decoder into AV_IMAGE_BGRA_32
          ▼
  sws_scale()  (FFmpeg libswscale)
          │ converts and scales frame to 512xH thumbnail in AV_PIX_FMT_BGRA
          ▼
  create_bitmap()  (jni/libavosjni/libavos.c)
          │ calls AvosBitmapHelper.createRGBBitmap() -> creates Android Bitmap
          ▼
[Storage & Persistence]
  MediaThumbRequest.execute()
          │ 1. Compresses Bitmap to JPEG (quality 85)
          │ 2. Saves to app_image_thumbs/<timestamp>.jpg
          │ 3. Inserts record into videothumbnail table
          │ 4. Generates random mini_thumb_magic and updates files table
          ▼
  waitForThumbnailReady() unblocks and returns true
          ▼
  VideoProvider returns cursor with generated thumbnail path
```

## 3. Key Classes and Modules

### `Video` (App module)
- `com.archos.mediacenter.video.leanback.presenter.PosterImageCardPresenter`:
  Checks if `posterUri != null`. If null, binds the card using `ThumbnailRequestHandler.buildUri(video.getId())`.
- `com.archos.mediacenter.video.leanback.nonscraped.NonScrapedVideosFragment`:
  Android TV grid displaying non-scraped videos (`m_id IS NULL AND s_id IS NULL`).
- `com.archos.mediacenter.video.picasso.ThumbnailRequestHandler`:
  Custom Picasso `RequestHandler` handling `thumbnail://<videoId>` URIs and invoking `VideoStore.Video.Thumbnails.getThumbnail()`.

### `MediaLib` (Media library module)
- `com.archos.mediaprovider.video.VideoStore`:
  Defines database contract, URIs (`VideoStore.Video.Thumbnails.EXTERNAL_CONTENT_URI`), and `InternalThumbnails.getThumbnail()`.
- `com.archos.mediaprovider.video.VideoProvider`:
  Main `ContentProvider` (`com.archos.media.videocommunity`). Coordinates thumbnail requests, queues them on a background `HandlerThread` (`"thumbs thread"`), manages retry attempts (`Archos_thumbTry`), and writes output JPEGs.
- `com.archos.medialib.MediaFactory`:
  Factory creating `IMediaMetadataRetriever` (`AvosMediaMetadataRetriever` with fallback to `AndroidMediaMetadataRetriever`).
- `com.archos.medialib.AvosMediaMetadataRetriever`:
  Java interface to native AVOS metadata retriever. Proxies remote streams via `StreamOverHttp`.
- `com.archos.medialib.AvosBitmapHelper`:
  Constructs Android `Bitmap` from native integer pixel buffers.

### `FileCoreLibrary` (Networking & file utilities)
- `com.archos.filecorelibrary.FileUtils`:
  Provides URI parsing helpers (`getName(Uri)`, `getParentUrl(Uri)`, `buildChildUri(Uri, String)`).
- `com.archos.filecorelibrary.StreamOverHttp`:
  Local HTTP proxy server translating network file protocols (SMB, SFTP, etc.) into local HTTP streams for native decoders.

### Native (`native/avos`)
- `Source/avos_mr.c`:
  Implements `avos_mr_getframe()`. Coordinates `thumb_stream`, retrieves the decoded video frame, and uses FFmpeg `swscale` (`sws_getContext`, `sws_scale`) to convert and downscale to 512-pixel wide thumbnails.
- `Source/thumb_stream.c`:
  Lightweight AVOS playback engine configured with `STREAM_THUMB | STREAM_MULTI` to open the stream, seek to the target time offset, and extract a single frame.
- `jni/libavosjni/avos_media_metadata_retriever.c`:
  JNI bridge between `AvosMediaMetadataRetriever` and native `avos_mr`.

## 4. Configuration & Safeguards

1. **Remote Thumbnails Preference**:
   - Preference key: `pref_create_remote_thumbs` (boolean).
   - In Settings: **Preferences → User Interface** / **Network**.
   - If `false`, thumbnail generation for remote URLs (`!FileUtils.isLocal(path)`) is skipped immediately.

2. **Retry Cap (`THUMB_TRY_MAX`)**:
   - `THUMB_TRY_MAX = 10` in `VideoProvider`.
   - Each failed attempt increments `Archos_thumbTry` in the database.
   - If `magic == 0 && nbTry >= THUMB_TRY_MAX`, thumbnail creation aborts without retrying.

3. **Active Scraping Lock**:
   - `VideoProvider.createVideoThumbnail()` checks `LoaderUtils.getScrapeInProgress()`.
   - While TMDb network scraping is actively running, thumbnail extraction is paused to avoid contending for network bandwidth and I/O.

## 5. Debugging with ADB Shell

All commands assume the device is accessible via `adb` (`adb -s <DEVICE_IP>:5555 shell ...`).

### 5.1 Check Remote Thumbnail Preference
Verify that remote thumbnail creation is enabled in Nova preferences:
```bash
adb shell "run-as org.courville.nova cat shared_prefs/org.courville.nova_preferences.xml | grep pref_create_remote_thumbs"
```
*Expected:* `<boolean name="pref_create_remote_thumbs" value="true" />`

### 5.2 List Non-Scraped Videos
Find videos in the database that do not have movie or show metadata:
```bash
adb shell "content query --uri content://com.archos.media.videocommunity/external/video/media --projection _id:_data:mini_thumb_magic:Archos_thumbTry --where 'm_id IS NULL AND s_id IS NULL'"
```

### 5.3 Trigger Thumbnail Generation for a Video
Run a blocking thumbnail query for a specific video ID (`<VIDEO_ID>`):
```bash
adb shell "content query --uri 'content://com.archos.media.videocommunity/external/video/thumbnails?blocking=1&orig_id=<VIDEO_ID>'"
```
*Output on success:*
```text
Row: 0 _id=19, _data=/data/user/0/org.courville.nova/app_image_thumbs/1789848698219.jpg, video_id=<VIDEO_ID>, kind=1, width=512, height=288
```

### 5.4 Check Generated Thumbnail Record
Query the `videothumbnail` table for a specific video:
```bash
adb shell "content query --uri content://com.archos.media.videocommunity/external/video/thumbnails --where 'video_id=<VIDEO_ID>'"
```

### 5.5 Count Total Generated Thumbnails
```bash
adb shell "content query --uri content://com.archos.media.videocommunity/external/video/thumbnails --projection 'count(*)'"
```

### 5.6 Check Thumbnail Files on Device Storage
```bash
adb shell "run-as org.courville.nova ls -lh app_image_thumbs/"
```

### 5.7 Inspect Logcat
Filter logcat for thumbnail and retriever operations:
```bash
adb logcat -d | grep -iE "VideoProvider|MediaThumb|AvosMediaMetadataRetriever|StreamOverHttp|avos_mr"
```

## 6. Important Caveats & Historical Fixes

- **URI Query Parameter Stripping**:
  `FileUtils.getName(Uri)` parses raw URI strings to preserve literal `#` characters in SMB folder names (e.g. `smb://server/share/#/video.mkv`). It **must** strip query parameters (`?query`) before extracting the basename; otherwise, content provider URIs with query parameters (such as `.../media/123?blocking=1&orig_id=123`) produce corrupted IDs (`123?blocking=1&orig_id=123`) that fail database lookups.
- **Clean Media URIs**:
  When converting thumbnail URIs to media URIs in `VideoProvider.queryThumbnail()`, `.clearQuery()` must be called so thumbnail query parameters (`blocking`, `orig_id`, `group_id`) do not leak into media table queries and updates.
- **Existing Thumbnail Fast-Path**:
  In `VideoProvider.waitForThumbnailReady()`, if `magic != 0` (thumbnail was already generated and valid), the method returns `true` immediately without queuing an unnecessary generation request.
